Getting started with MT5 and VORTEX AI

This guide covers MetaTrader 5 installation, broker compatibility, connecting a trading account, demo testing and safe credential handling. The website dashboard is read-only; it does not connect directly to your broker or place orders.

Release status: Limited access · integration testing. VORTEX AI is not generally available and public customer onboarding is closed. Follow this guide to prepare an MT5 test environment only; do not treat completion as approval to use a real-money account with the bot.

1. Install the official MetaTrader 5 terminal

For the Windows trading computer, download the desktop terminal from MetaTrader or MetaQuotes. Use the broker-provided installer instead when your broker explicitly requires its branded terminal or server configuration.

Official MetaTrader 5 downloads ↗MetaQuotes downloads ↗
  1. Install the Windows desktop application from an official source.
  2. Launch MT5 and allow it to update.
  3. Keep the trading terminal on a secured Windows PC or managed VPS that you control.
  4. Do not download modified installers or Expert Advisors from unknown file-sharing sites.

Official platform downloads are available for desktop and mobile. Use the official source for the device you are setting up. MetaTrader 5 download page.

2. Confirm broker and account compatibility

VORTEX AI is built around MetaTrader 5 (MT5), not MetaTrader 4 (MT4). A broker being listed inside the MT5 terminal does not by itself prove that its account, server, symbols or execution settings have been tested with this VORTEXT build.

  • Ask the broker for the exact MT5 server name and whether your account is a demo or real account.
  • Confirm that the broker offers the instruments you intend to monitor. The current configured roster is XAUUSD, EURUSD, GBPUSD, USDJPY, NAS100, US30 and BTCUSD; brokers may use different symbol names or suffixes.
  • Check contract size, tick size, trading hours, margin rules, commissions, swaps and account type with the broker.
  • Confirm whether the account uses hedging or netting and whether the MT5 server provides the history and data required by the configured bot.
  • Compatibility must be verified for the specific broker server, account type and symbol mapping. No universal broker-compatibility claim is made.

MT5 login requires the account number, password and exact server name supplied by the broker. The wrong server can prevent a valid account from connecting. Official MT5 account-connection instructions ↗.

3. Connect an account in MT5

Find your broker server

In MT5, open the account or server search. Search for your broker and select the exact server name given by the broker. Do not guess between similarly named Demo, Live, or regional servers.

Connect an existing demo account

Use File → Login to Trade Account (wording can vary by terminal version). Enter the demo account login, password and exact server provided by the broker. Check that the connection indicator updates and quotes are arriving.

Or create a demo account

Use File → Open an Account, select the broker's server, then choose the demo-account option when the broker offers it. Follow the broker's own verification and account limits.

Verify symbols and history

Open Market Watch, locate the exact instrument symbols, and check that charts, quotes and account history populate. Record symbol suffixes exactly; do not rename instruments to make an unsupported symbol appear compatible.

MT5 supports demo and real account types, but a real account is opened by a broker. Demo accounts use virtual funds and are intended for training and strategy testing. Official MT5 account-opening guide ↗.

4. Test with a demo account first

  • Use a broker-issued MT5 demo account and confirm the terminal remains connected through a normal session.
  • Verify symbol mapping, historical data, time zones, account currency, spreads and execution settings.
  • Observe the bot and dashboard without assuming a signal is a broker fill. Compare any displayed position or deal with the MT5 Trade and History tabs.
  • Check that the dashboard's feed state changes to stale when new snapshots stop arriving, and that the last broker-update timestamp does not keep advancing without a new snapshot.
  • Do not switch the bot to a real-money account based only on a successful installation or demo result. Real-account use requires a separate, explicit release and risk review.

5. Safe account and credential setup

  • Use a dedicated demo account for testing. Keep it separate from personal savings, investment accounts and any real-money account.
  • Use a unique, strong password for the broker account and enable the broker's available security controls and two-factor authentication.
  • Enter broker credentials only in the official MT5 terminal or the broker's verified application. Never send passwords, one-time codes, recovery codes, HMAC secrets or Supabase keys to VORTEX AI support, GitHub or chat.
  • The website login is separate from MT5 authentication. VORTEX AI never needs your MT5 password in the browser.
  • Keep the Windows terminal, local account registry and environment secrets on the secured trading computer. Do not upload `.env`, `accounts.json`, terminal databases or credential screenshots.
  • Do not enable automated trading or attach the bot to a real account during this testing phase. A real account may lose money, and a demo result is not evidence of future performance.
  • Before any future real-account use, verify the broker, account mode, symbol mapping, risk limits, rollback/disable procedure and monitoring with the operator.

MT5 offers an investor access type that is generally view-only at the terminal level; ask your broker whether it is available and whether it meets the specific data requirements. Do not assume an investor password is supported by the bot integration. MT5 access types ↗.

6. What happens after setup?

During the current limited-access test, the Windows MT5 process and a separate signed publisher are responsible for sending account snapshots to the secured backend. The browser dashboard can only display the accounts included in the server's shared read-only feed after sign-in. The dashboard itself cannot send orders to MT5.

Broker compatibility, live snapshot delivery, account authorization and feed freshness must be verified before customer release. Completing the steps on this page does not create an account, grant access or activate trading.
