Market intelligence & execution controls

VORTEX AI combines live tick and price data with rule-based analysis and risk controls. Data availability depends on the MT5 broker, instrument and active terminal connection.

≋

Depth of Market (DOM)

Uses broker-provided bid/ask levels when available: order-book imbalance, liquidity concentration, walls, thin zones and price-ladder pressure. When Level II data is unavailable, a tick-based fallback estimates pressure; it is not a real order book.

⇄

Order-flow analytics

Tick imbalance, price velocity and acceleration, rolling cumulative-delta approximation, estimated aggressive buy/sell pressure and participation-rate analysis.

⌁

Market microstructure

Detects structure breaks (BOS), change of character (CHoCH), potential liquidity grabs, failed breakouts, absorption patterns, Fair Value Gaps and momentum exhaustion.

◷

Multi-timeframe & volume

Uses M1, M5, M15 and H1 market data, EMA trend alignment, ATR volatility checks, relative-volume changes, spikes and directional-volume estimates.

◇

Risk management

ATR-based stop-loss/take-profit distances, configured risk-per-trade sizing, exposure checks, drawdown/circuit-breaker controls, trailing stops, breakeven and time-stop management.

✓

Execution & reconciliation

Tracks broker execution results, slippage/latency metrics and position reconciliation. The website is read-only and displays broker-confirmed data only when the secure feed is connected.

Trust, Security & Data Hygiene

Derived directly from our software architecture, database constraints, and cryptographic transport guarantees:

No Web Broker Passwords

MetaTrader 5 broker credentials remain strictly on your local PC in Windows Credential Manager. You never enter broker passwords into this website.

HMAC-SHA256 Signed Ingestion

All telemetry packets sent from local MT5 daemons require cryptographic timestamping and SHA-256 signatures with nonce replay protection.

Cloud SSO & Strict RBAC

Authentication utilizes Supabase Cloud SSO with HS256 JWT validation. Non-admin users are strictly restricted to read-only fleet visibility.

Hard Disarmed Safety

The global execution controller is hard-disarmed. All 20 accounts maintain trading_enabled: false to guarantee zero unintended trade entries.

Connect to MT5 on your phone

Use the official MetaTrader 5 mobile app. Never enter your broker password on VORTEX AI.

Android

Cannot find MT5 in Google Play? Download the APK directly from the download link provided by MetaTrader's official website.

Download official MT5 APK ↓ Official MT5 page ↗
  1. Download the APK from the official MetaTrader page's APK link.
  2. Open the downloaded file and, if Android asks, allow this browser or file manager to install unknown apps.
  3. Install MT5, then turn off that install permission again.
  4. Open account management and add an existing account.
  5. Search for your broker and select the exact server.
  6. Enter broker credentials only inside the official MT5 app; check the Trade and History tabs.

The link opens the APK download hosted by MetaTrader's linked download endpoint. Do not install APKs from third-party mirror sites.

iPhone

  1. Install MetaTrader 5 from the Apple App Store.
  2. Open Settings or Accounts and add an existing account.
  3. Search the broker, then select the correct server.
  4. Enter trading-account credentials inside the official MT5 app.
  5. Verify connection and review open positions and History.
